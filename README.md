# Currículo Digital – EJA Dom Bosco

Página para os estudantes da EJA e da AJA da Escola Estadual Dom Bosco (Corumbá – MS) montarem o currículo no celular e baixarem em PDF.

- Tudo acontece no próprio aparelho: nenhum dado é enviado ou guardado em servidor.
- Estrutura: dados de contato, resumo profissional, objetivo, formação, experiência, cursos e habilidades.
- Fontes: Blinker e Bodoni Moda (SIL Open Font License).
